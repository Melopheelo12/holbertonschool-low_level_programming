# holbertonschool-low_level_programming

# ⚙️ Low Level Programming

This repository contains all the projects completed as part of the **Holberton School Full-Stack Software Engineering program**, focused on **low-level programming in C**.

The goal of this repository is to build a deep understanding of:
- Memory management 🧠
- Pointers and data structures 🔗
- Algorithms and problem solving ⚡
- Linux/Unix system programming 🐧

---

## 📚 Project Overview

Each directory represents a specific concept of the C programming language:

### 🧩 Fundamentals
- `0x00-hello_world` → Introduction to C, compilation process
- `0x01-variables_if_else_while` → Variables, conditions, loops
- `0x02-functions_nested_loops` → Functions and nested loops
- `0x03-more_functions_nested_loops` → Advanced functions

### 🔗 Memory & Data Structures
- `0x04-pointers_arrays_strings` → Pointers, arrays, strings
- `0x05-pointers_arrays_strings`
- `0x06-pointers_arrays_strings`
- `0x07-pointers_arrays_strings`
- `0x08-recursion` → Recursive functions

### 🧠 Advanced Memory Management
